# Predictive Maintenance System

A machine learning-based predictive maintenance solution that helps identify potential equipment failures using historical operational data. The system analyzes patterns in machine performance and provides predictions to support proactive maintenance decisions.

## Features

* Data preprocessing and transformation
* Machine learning model training and evaluation
* Equipment failure prediction
* Flask-based web interface
* Modular and scalable project structure

## Tech Stack

* Python
* Flask
* Pandas
* NumPy
* Scikit-learn
* HTML & CSS
